# نظام مخزون وادي الخيام

نظام كامل (خلفية + واجهة + قاعدة بيانات) لإدارة مخزون مستودع مؤسسة وادي الخيام، بتسجيل دخول حقيقي بيوزر وباسورد، وثلاثة أدوار (مدير / محاسب / مستخدم)، ويتزامن مع متجركم على سلة عبر مهمة مجدولة تعمل من خلال Claude.

## 1) قاعدة البيانات (مجانية — Neon)

1. روح على https://neon.tech وسجّل حساب مجاني (بالإيميل أو GitHub، من غير بطاقة ائتمان).
2. اعمل مشروع جديد (New Project) — أي اسم، أي منطقة قريبة (Frankfurt مثلاً).
3. من صفحة المشروع، انسخ **Connection string** (شكلها `postgresql://user:pass@host/dbname?sslmode=require`) — هتحتاجها في الخطوة الجاية.

## 2) الاستضافة (مجانية للبداية — Render)

1. ارفع محتوى هذا المجلد على مستودع GitHub خاص بيك (لو مش عندك حساب GitHub، اعمل واحد مجاني — من غير حاجة لأوامر git، ممكن تسحب وتفلت الملفات من صفحة "Add file → Upload files" في مستودع جديد).
2. روح على https://render.com وسجّل حساب مجاني، واربطه بحساب GitHub بتاعك.
3. من الداشبورد: **New + → Web Service** → اختار المستودع اللي رفعته.
4. الإعدادات:
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Plan: **Free**
5. تحت **Environment Variables** ضيف القيم دي (انسخها زي ما هي، أو غيّرها لقيم عشوائية تانية بنفس الطول):

   ```
   DATABASE_URL = (الـ connection string اللي نسخته من Neon في الخطوة 1)
   JWT_SECRET   = 7e1c7e0d74618f885c508b2562d8427c7e88fa179e1187b77e4a82321b79792f
   SYNC_API_KEY = ccb31ccb9c91d11202e3b0823cc44e9a4309142b1b4d9c06
   NODE_ENV     = production
   ```

6. اضغط **Create Web Service** واستنى لحد ما يخلّص البناء والتشغيل (بياخد دقيقتين تقريباً). هتاخد رابط زي `https://wadi-inventory.onrender.com`.

> ملاحظة: الخطة المجانية في Render بتنام بعد 15 دقيقة من غير استخدام، وأول طلب بعد النوم بياخد كام ثانية إضافية لحد ما يصحى. مناسب تماماً لأداة داخلية بيستخدمها فريقك خلال ساعات الشغل، ومهمة المزامنة الساعية هتخليه صاحي بشكل شبه دائم.

## 3) تجهيز البيانات لأول مرة

من صفحة الخدمة في Render، افتح تبويب **Shell** (لوحة تحكم الخدمة نفسها) ونفّذ:

```
npm run seed
```

ده هيزرع الـ 159 صنف الحقيقي المستورد من متجركم على سلة، ويعمل أول حساب **مدير**:

```
اسم المستخدم: manager
كلمة المرور:  mJvG5E4w
```

سجّل دخول بيهم على رابط الموقع، وغيّر كلمة المرور فوراً من **الإعدادات → المستخدمون**، وضيف حسابات المحاسب وخدمة العملاء من نفس الشاشة.

## 4) وصل المزامنة مع سلة

بعد ما يبقى عندك الرابط الفعلي (زي `https://wadi-inventory.onrender.com`) و SYNC_API_KEY، ابعتهملي في المحادثة وأنا هحدّث مهمة المزامنة المجدولة عندي عشان تتصل بالنظام الجديد بدل النسخة القديمة، وهتفضل شغالة أوتوماتيك كل ساعة زي ما هي دلوقتي.

## هيكل المشروع

```
server/          كود الخلفية (Express + PostgreSQL)
  routes/        auth, users, products, movements, sales, reports, sync
public/          الواجهة (HTML/CSS/JS عادي، بدون أي إطار عمل خارجي)
scripts/seed.js  زرع المنتجات + أول حساب مدير
```

## التشغيل محلياً (لو حابب تجرب على جهازك قبل الرفع)

```
cp .env.example .env   # وعدّل القيم
npm install
npm run seed
npm start
```
